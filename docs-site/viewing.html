Viewing simulations

Map any variable in a simulation's output, at the time, depth and years you choose.

On this page
  • Choosing the simulation
  • The viewer
  • The map

View simulation output lets you look at what a simulation’s netCDF files hold, and map any variable in them at the time, depth and years you choose. Run oceanval in a terminal and choose View simulation output. Nothing is written but a record of the files’ times, and only the map on show is ever read from the files: one time step at one depth of one file, so output of many GB stays quick to look at.

oceanval

Choosing the simulation

  1. Give the directory the output is in (or the path of a single file) and how many directories down its files are. OceanVal fills the number in when it recognises the folders. The arrow in the directory box lists simulations you have viewed before.
  2. Use Skip file names containing to leave files out. It starts with restart and spinup in its list; type a word and press Enter to add one, and the × beside a word removes it. Only include file names containing starts with no terms. View the files in a random subdirectory, beside the count of files, lists the names of the files the filters let through in one folder.
  3. Optionally give Missing values: numbers in the files that mean there is no data, such as 0 or -999. OceanVal looks for a value that the same cells have in every file and fills it in for you to check.
  4. Continue reads the variables of the first file of each kind and opens the viewer straight away. The times of all the files are read in the background; until they are in you can map the first time of any variable. They are kept in .oceanvaltimes in your home directory, so a simulation opened again has them at once.

The viewer

On the left, search the variables by name, description or units (* stands for any characters and ? for one, so P*_Chl finds P1_Chl and P2_Chl). Clicking a variable maps it. To map the sum of several variables, use their + buttons (a − takes one out; a + that is greyed out cannot be added to those chosen). The controls are:

  • Years: a first and a last year; Time and Play stay inside them.
  • Time: a slider, arrow buttons, and Play, which animates the simulation at Slow, Normal or Fast on one colour scale, keeping your zoom.
  • Depth: the level to show.
  • Colours: the colour map, fixed limits or an automatic scale, a logarithmic scale and coastlines.

The map

On the right is the map, which you can zoom, pan, hover over to read values, and save as a PNG. It keeps the area’s true proportions and is fitted again when the window is resized. Regular and curvilinear grids, regional models, unstructured grids (such as ICON and FESOM) and FVCOM meshes are all drawn.

The full description of every control is in The OceanVal app. To look at a simulation’s climatologies and time series, see Analyzing simulations.
